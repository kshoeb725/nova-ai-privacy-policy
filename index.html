Overview of App Features & Privacy Philosophy

Nova AI Wallpaper Agent brings dynamic, interactive cyberpunk companions directly to your Android home screen, lock screen, and floating edge panel. Nova and Luma react to touches, display live audio visualizers, and execute user-directed device actions.

Our core architecture follows a strict privacy-first and on-device-first design:

  • No Hidden Telemetry or Account Tracking: The application does not require user account registration, phone numbers, or third-party advertising SDKs.
  • Isolated Companion Memory: Personal conversation notes and companion memory are stored locally on your device in a sandboxed SQLite database via Android Room, isolated to the application's private Linux UID directory.
  • Explicit User Control: Cloud AI capabilities are completely optional and disabled by default until the user explicitly turns them on in Settings.

Optional Cloud AI (Google Gemini Developer API — Data Disclosures & Service Tiers)

When you explicitly enable Optional Cloud AI Mode in Settings, conversational queries are processed using Google LLC's Gemini Developer API (via the standard developer REST endpoint generativelanguage.googleapis.com) over encrypted HTTPS connections.

Actual Data Transmitted to Gemini When Cloud AI is Enabled:

  • User Prompts: Your typed or speech-transcribed query.
  • Recent Conversation Context: Recent active in-memory conversation context (up to 20 conversation turns formatted with speaker labels) to preserve dialogue continuity.
  • Memory Summaries: Relevant long-term companion memories and extracted preferences from local SQLite storage (e.g. favorite topics, user-specified goals).
  • Explicitly Approved Screen Captures: Only when you tap "Explain Screen" and approve the system MediaProjection consent prompt, a single static frame is captured into volatile memory, scaled down (max 1024px JPEG), and sent to Gemini Vision. Screenshots are never saved to permanent storage.
  • Active Companion Identity: System prompt instructions configuring the active companion persona (Nova or Luma).

Service Tiers Based on Project Billing Status:

  • Free Tier (Unbilled Projects): When using an API key associated with an unbilled Google AI Studio / Google Cloud project, Google may retain prompts, responses, and related materials, and human reviewers may inspect them to train and refine Google models. Users should not input confidential or sensitive personal information when operating on the Free Tier.
  • Paid Tier (Billing-Linked Projects): When you configure a custom Gemini API key associated with a Google Cloud project with billing activated, Google's paid customer terms apply, under which customer data is not used for model training. Note that standard Paid-tier terms do not constitute custom zero-retention or zero-logging agreements; Google retains operational and security logs under standard developer cloud terms.
  • Client-Side Socket Disconnection: When you disable Cloud AI or cancel a query, the application severs the local network socket. This halts device-side transmission, but cannot guarantee cancellation of server-side processing for packets that already reached Google's infrastructure prior to disconnection.
  • Cross-Border Transfer: Cloud AI requests are processed in Google Cloud data centers located in the United States and globally in compliance with applicable cross-border transfer frameworks.

AI Safety Reporting & Third-Party Processors

Nova includes an optional safety reporting feature allowing users to report offensive, harmful, inaccurate, or policy-violating AI responses directly to the developer:

  • Voluntary, User-Initiated Submissions: A safety report is never transmitted automatically; it is generated solely when you tap "Report Issue" on an AI response, inspect the preview, and tap "Confirm & Send".
  • Opt-In Response Excerpt (Excluded by Default): The AI response excerpt is excluded by default (transmitted as an empty string) unless you explicitly check the opt-in box to include it. Original conversation history and user prompts are never attached.
  • Client-Side Privacy Sanitization: Before transmission, client-side regex sanitizers scan the optional excerpt and feedback to redact email addresses, phone numbers, IP addresses, and cryptographic keys. Any excerpt containing multiple sensitive entities or private keys is automatically dropped entirely. Automated detection cannot guarantee complete redaction; users should avoid including personal names in optional feedback.
  • Anonymous Serverless Relay & Abuse Protection: Reports are submitted anonymously without user account creation over encrypted HTTPS to a Supabase Edge Function (submit-ai-report). The server applies payload schema validation, client-side rate mitigation, and ephemeral rate-limiting storing salted SHA-256 hashes of client IP addresses with a 10-minute expiration. Optional Play Integrity tokens may be forwarded where supported by the client environment, but are not guaranteed across all operating configurations.
  • Email Delivery to Developer Mailbox: Verified reports are delivered via Resend's transactional email service directly to the developer's permanent operational email inbox (shoebbussiness786@gmail.com). Reports are retained as email correspondence for security triage, prompt filter improvement, and quality assurance until manually reviewed and archived or deleted by the developer.
  • Third-Party Processors: Supabase Inc. (edge function execution and rate limiting) and Resend Inc. (transactional email dispatch) process report data and standard connection metadata (IP addresses, timestamps) in accordance with their respective privacy policies.

Security Safeguards, Cryptography & Backup Exclusions

We implement multi-layered technical safeguards to protect data integrity and confidentiality:

  • Network Transport Security: All external network communications (Google Gemini API and Supabase reporting) explicitly use encrypted HTTPS (TLS 1.2 / TLS 1.3) connection endpoints. Insecure cleartext HTTP traffic is blocked by default by modern Android platform security policies (API 28+).
  • Hardware-Backed Keystore Encryption: User-supplied custom Gemini API keys are encrypted at rest with AES-256 GCM authenticated encryption using keys generated and isolated within the hardware-backed Android Keystore (TEE / StrongBox) on supported devices (with software cryptographic fallback on devices lacking hardware security modules).
  • Android Application Sandboxing: Companion memories and settings are stored in local SQLite databases (wallpaper_agent_memory.db, ai_response_reports.db) within the application's private internal storage directory, isolated by Android's Linux UID sandbox permissions (0600). No database-level SQLCipher encryption is applied to the SQLite file itself.
  • Android Cloud Backup Exclusions: Pursuant to privacy-by-design, all local databases, SharedPreferences, Keystore keys, and SAF folder tokens are explicitly excluded from automated Google Drive cloud backups and device-to-device transfers in backup_rules.xml (API < 31) and data_extraction_rules.xml (API 31+).

User Privacy Rights, Data Erasure & Uninstall Clarification

Under Section 12 of the DPDP Act 2023 and Google Play User Data Policies, you maintain complete sovereignty over your data:

  • Delete Individual Memories: Tap the delete icon next to any remembered item in Settings → Memory & Privacy to immediately remove it from local storage.
  • Clear All Memories: Tap "Clear All Memories" in Settings → Memory & Privacy to physically purge all saved facts and notes from local storage.
  • Purge Conversation History: Tap "Clear Conversation History" in Settings → AI & Offline Mode to instantly wipe volatile in-memory context.
  • Withdraw Cloud AI Consent: Toggle off "Cloud AI Mode" in Settings at any time to immediately cease all communication with Google Gemini.
  • App Uninstall vs. Transmitted Reports: Uninstalling Nova completely deletes all local databases, preferences, and Keystore keys from your device. However, uninstalling the app does not automatically delete safety report emails previously delivered to the developer's inbox or technical connection logs held by third-party cloud infrastructure (Google, Supabase, Resend). To request deletion of prior email correspondence, contact the developer at shoebbussiness786@gmail.com.
